# UI direction mockups

Static HTML mockups used to make `docs/ui-directions.pdf`. Fonts come from `@fontsource/*` packages (install them in this folder to re-render): `npm i @fontsource/cinzel @fontsource/cormorant-garamond @fontsource/orbitron @fontsource/space-grotesk @fontsource/manrope @fontsource/baloo-2 @fontsource/yatra-one`, then `node shot.cjs a-royal b-neon c-clean d-festive && node build-pdf.cjs`.
